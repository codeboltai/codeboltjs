Current Gap

Remote tool execution still needs the capability bridge

The deployed MiniApp route /__codebolt/tools/add-lead is reachable, but the handler fails with Remote MiniApp execution context is unavailable.

This comes from packages/miniapp/src/index.ts: remote execution expects an execution token and a cloud capability URL so calls like db.set, blob.put, and tasks.create can be proxied back to CodeBolt cloud.
